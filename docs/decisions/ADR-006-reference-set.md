# ADR-006 — Reference set from the Reuters Institute Digital News Report 2026
**Initial approach:** hand-picked "major outlets spanning the spectrum".
**Explored:** top 5 measurable domestic news brands per country by weekly online reach (DNR 2026), with explicit rules
(no aggregators, foreign brands or video-only brands; skip unreadable feeds).
**Evidence:** the reach-based list added GB News, Nettavisen, Ekstra Bladet, B.T., Bild and OKDiario — the hand-picked list
had under-represented high-reach right-leaning and tabloid brands.
**Decision:** two tiers — 50 reference outlets define the origin and country positions; extras are shown relative to them.
