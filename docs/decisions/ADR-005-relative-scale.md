# ADR-005 — Relative positions only
**Common approach:** absolute bias ratings (e.g. human-panel "Left / Center / Right" labels).
**Decision:** everything is relative — outlets to outlets, countries to countries; (0, 0) is the average reference outlet,
not a political centre. Nobody agrees where the centre is; pairwise comparisons never need one.
**Consequence:** the reference set defines "average" → chosen by an external, citable criterion (ADR-006).
